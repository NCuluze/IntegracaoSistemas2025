Instruções de Compilação e Execução

Este documento descreve os passos necessários para compilar, configurar e executar as aplicações cliente gRPC desenvolvidas para testar os serviços da Entidade de Registo e da Entidade de Votação.

1. Pré-requisitos
Antes de iniciar, é necessário garantir que o sistema dispõe dos seguintes requisitos:
- Python versão 3.9 ou superior
- pip (gestor de pacotes Python)
- Ligação à Internet para acesso ao serviço remoto gRPC

2. Obtenção do projeto
O projeto deve ser obtido através do repositório GitHub:
git clone <https://github.com/NCuluze/IntegracaoSistemas2025/tree/master>
Após a clonagem, aceder à pasta raiz do projeto.

3. Criação de ambiente virtual (opcional)
Recomenda-se a criação de um ambiente virtual para isolar dependências.

Windows:
python -m venv venv
venv\Scripts\activate

Linux / macOS:
python3 -m venv venv
source venv/bin/activate

4. Instalação das dependências
As dependências do projeto encontram-se listadas no ficheiro requirements.txt.
pip install -r requirements.txt

5. Geração dos ficheiros gRPC
Os ficheiros *_pb2.py e *_pb2_grpc.py são gerados automaticamente a partir dos ficheiros .proto.

Criar a pasta de destino (se não existir):
mkdir generated

Gerar os ficheiros (Windows PowerShell):
py -m grpc_tools.protoc -I protos --python_out=generated --grpc_python_out=generated protos/voter.proto protos/voting.proto

6. Execução da aplicação da Entidade de Registo
python registration_client.py
O utilizador deverá introduzir o número do Cartão de Cidadão para obter uma credencial de voto.

7. Execução da aplicação da Entidade de Votação
python voting_client.py
A aplicação permite consultar candidatos, votar e consultar resultados.

8. Nota sobre indisponibilidade do serviço
Caso ocorra o erro StatusCode.UNAVAILABLE, significa que o serviço remoto não se encontra acessível. Este problema está relacionado com conectividade ou disponibilidade do servidor.

9. Estrutura do projeto
O projeto encontra-se organizado da seguinte forma:
- protos/
- generated/
- registration_client.py
- voting_client.py
- requirements.txt

10. Observações finais
Este projeto foi desenvolvido exclusivamente para fins académicos, com recurso a serviços gRPC mock, tendo como objetivo o estudo da integração de sistemas distribuídos.
